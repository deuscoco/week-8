# 🏊‍♂️ Hydra - Swimming Competition Management System

**Hydra** adalah aplikasi web berbasis **Google Apps Script** yang dirancang untuk membantu pengelolaan lomba renang secara digital, efisien, dan terintegrasi.

Mulai dari pendaftaran peserta hingga publikasi hasil lomba, semua dapat dikelola dalam satu sistem.

## ⚙️ Features
- 📝 Online participant registration  
- 📅 Race schedule management  
- ⏱️ Time recording system  
- 📊 Live results & leaderboard  
- 📑 Automatic reports & recap  

---

## 🛠️ Tech Stack
- **Google Apps Script** (Backend & Deployment)  
- **HTML, CSS, JavaScript** (Frontend)  
- **Google Sheets** (Database)  

---

## 📌 How It Works
1. Admin menginput atau mengelola data lomba  
2. Peserta mendaftar melalui sistem  
3. Sistem mengatur jadwal dan kategori  
4. Hasil lomba dicatat dan ditampilkan secara real-time  

---

## 🎯 Purpose
Hydra dibuat untuk meningkatkan:
- Efisiensi penyelenggaraan lomba  
- Akurasi pencatatan hasil  
- Kemudahan akses informasi
